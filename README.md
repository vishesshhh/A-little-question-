# Romantic dear — animated recreation ❤️

This version recreates the provided sequence with additional playful interaction:

- Floating hearts and glowing particles continuously animate in the background.
- Hearts bob and a heart burst appears when the first challenge is completed.
- The "Let's go" transition has a heart burst.
- The secret keyboard has a glowing expected letter, incorrect-letter shake, and keyboard interaction.
- The "Maybe 👀" button moves to a new position every time it is pressed.
- The YES button becomes more attention-grabbing after attempts to choose Maybe.
- A final heart burst and animated final screen appear after YES.

Run with:

```bash
npm install
npm run dev
```

Build for deployment:

```bash
npm run build
```
